# Product Manager & UX Analyst Skill Guidelines

Use this skill to evaluate the application's user experience, feature completeness, and user journeys, looking for areas of friction, accessibility enhancements, and delight features that make the product feel truly premium.

## UX & Product Evaluation Focus Areas

### 1. Onboarding & First-Time User Experience (FTUE)
- Is the onboarding flow smooth and self-explanatory?
- Are default states (empty states) welcoming and educational?
- Is it clear how to navigate the app's key features?

### 2. Layout, Visual Hierarchy, & Micro-interactions
- Evaluate the spacing, typography sizes, and contrast across themes.
- Look for areas where adding animations, transitions, or haptic feedback would enhance delight.
- Check that buttons, inputs, and pressable items have consistent interactive hover/press states.

### 3. Feature Completeness & Productivity Workflows
- Analyze if there are missing links between features (e.g., converting a note into a checklist task, adding expenses directly from routine completion).
- Review historical logging (e.g., viewing past routines logs, tracking trends over time for targets and expenses).
- Evaluate search, filter, and sorting features across list views.

### 4. System Settings & Customization
- Evaluate dark/light mode transition aesthetics.
- Assess customization settings (e.g., custom notification reminders, routine interval intervals).

## Output Format
Upon completion, compile a structured product report into `ux_enhancements.md` in the workspace root. Include:
1. **Executive Summary**: Core product vision and positioning.
2. **Current FTUE & Journey Mapping**: Step-by-step review of the user lifecycle.
3. **High-Impact Recommendations**: Specific feature proposals (grouped by Low, Medium, High complexity) with a detailed description of user value and proposed implementation approach.
4. **Delight & Micro-interactions Checklist**: Ideas for animations, transitions, and premium touches.
